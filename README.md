# 🏠 HEARTH AI

AI-powered service marketplace connecting customers with trusted professionals across 20+ categories.

## 📁 Project Structure

| Directory | Stack | Description |
|-----------|-------|-------------|
| `frontend/` | Next.js + TypeScript + Tailwind | Customer web app + Admin panel + Pro dashboard |
| `backend/` | Node.js + Express + TypeScript + MongoDB | REST API + WebSocket + AI integration |

## 🚀 Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## 📊 Features

- **40 pages** — complete marketplace: landing, services, booking, dashboards, admin
- **Neumorphism UI** — soft-shadow design, no glassmorphism
- **AI-powered** — Gemini AI for matching, recommendations, review analysis
- **Real-time** — WebSocket chat, notifications
- **Secure** — Razorpay payments, verified professionals, background checks
